YouTube-Ad-Skip per DNS

Das Userscript /userscript.js markiert YouTube-Wiedergabelinken, die von den Blocklisten betroffen sind, und überspringt sie automatisch.

Hinweis: Das Blockieren von YouTube-Einblendungen läuft über die Blocklisten; das Addon setzt die Wiedergabe dort fort, wo die Engine sie erkannt hat.

Installations-Snippet

Installiere das Userscript z. B. per Tampermonkey/Greasemonkey mit @match https://www.youtube.com/*.

Danach auf der Testseite prüfen: YT-Suchbegriff → Blockstatus → Addon greift.
